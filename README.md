# AI4EOSC demo agent

[![Conventional Commits](https://img.shields.io/badge/Conventional%20Commits-1.0.0-%23FE5196?logo=conventionalcommits&logoColor=white)](https://conventionalcommits.org)

This is a reference implementation for users on how to define an agent (or several of them) that can run in the platform.

The repo provides several definitions of the _same_ agent using the main agent frameworks. The frameworks currently demoed are [PydanticAI](https://github.com/pydantic/pydantic-ai) and [Langgraph](https://github.com/langchain-ai/langgraph), although any frameworks compatible with the A2A protocol is supported.

All the agents are then exposed under a single endpoint using [a2a-sdk](https://github.com/a2aproject/a2a-python) framework.
